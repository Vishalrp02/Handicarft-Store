# Handcrafted Storefront UI

The product is handmade, so the interface must feel considered and specific. Before writing UI, read this, then use `impeccable` (or `frontend-design`) for craft details.

## Direction
- The craft is the hero. Large, honest product photography (natural light, texture close-ups, scale shots in a real room). UI chrome stays quiet around it.
- Tell the maker's story: artisan name, village/region, technique (block print, blue pottery, dhokra, kantha…), time taken. Every product page links to an artisan profile.
- Warm, material palette taken from the crafts themselves: indigo, madder red, turmeric, terracotta, undyed cotton, kohl black. One dominant neutral, one accent. Define as CSS tokens; no ad-hoc hex values.
- Typography: one characterful serif or humanist face for headings, a clean, readable text face for body. Never default Inter/Roboto/system-ui for headings. Set a real type scale; generous line-height for body copy.
- Layout: editorial, asymmetric where it helps (magazine-style story blocks), strict grid for product listings. Vary section rhythm; not every section is a centered heading + 3 cards.

## AI tells to avoid (reject on sight)
- Purple/blue gradients, glassmorphism, glowing blobs, neon accents.
- Emoji as icons; generic "✨" sparkle language.
- Three identical feature cards with icon + title + two lines.
- Every section centered; identical padding everywhere; pill buttons on everything.
- Fake stats ("10,000+ happy customers"), lorem-style copy, stock-photo smiling teams.
- Gray text on colored backgrounds; low contrast "elegant" text.

## Copy
- Concrete, short, human: "Hand block-printed in Bagru. 3 days per metre." beats "Discover timeless elegance".
- Buttons say what happens: "Add to bag", "Pay ₹2,450". Prices in ₹ with Indian digit grouping (₹1,24,500).
- Note honest variation: "Each piece is handmade; colour and pattern may vary slightly."

## Commerce UX that must be right
- Mobile first (most Indian shoppers are on phones); test at 360px width.
- One-of-a-kind items: show "Only 1 left — this exact piece" and handle sold-out gracefully.
- Show delivery estimate by pincode, COD availability, returns policy near the price.
- Checkout: minimal fields, UPI first, clear error states, no surprise charges at the last step.
- Accessibility: alt text that describes the craft, focus states, 4.5:1 contrast, keyboard-usable gallery.
- Fast: lazy-load images, responsive `srcset`, WebP/AVIF, no heavy animation libraries for small effects.

## Process
1. Before the first screen, write/agree a short `DESIGN.md` (palette tokens, type scale, spacing scale, component rules). Reuse it on every page.
2. Build, then run `/impeccable critique` and `/impeccable polish` on the result.
3. Run `web-design-guidelines` review before calling a page done.
